## Full Description
Kith is the ultimate companion for modern travellers, shared living, and financial enthusiasts. Track shared expenses offline, settle up with UPI, and manage your family's Demat IPO applications seamlessly in one high-performance app.

### Key Features:
- **Offline-First Expense Tracking:** Add expenses on flights, road trips, and remote destinations with zero network lag.
- **Smart P2P & Cloud Sync:** Real-time peer-to-peer sync via local Wi-Fi/hotspot and encrypted cloud synchronization.
- **Exact Paise Arithmetic:** Zero floating-point rounding errors with sub-cent precision.
- **Multi-Account IPO Tracking:** Plan, record, and monitor multi-demat IPO applications across family profiles.
- **Live Market Updates & Indicative GMP:** Stay ahead with active and upcoming Mainboard and SME IPO schedules.
